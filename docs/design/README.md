# UI Design Direction

This project uses three design references with separate responsibilities:

| Area | Design Source | File |
|---|---|---|
| Core UI | Linear | `core-ui-linear.md` |
| Dashboard | Vercel | `dashboard-vercel.md` |
| Document | Notion-lite | `document-notion-lite.md` |

## Core Framework

| Technology | Purpose |
|---|---|
| Next.js 16 | React fullstack framework for SSR, routing, API routes, SEO, and performance. |
| React 19 | Main UI library for components, state, and lifecycle. |
| TypeScript | JavaScript superset for safer, more maintainable code. |

## UI & Styling

| Technology | Purpose |
|---|---|
| Tailwind CSS v4 | Utility-first styling for fast, compact UI work with minimal custom CSS. |
| shadcn/ui | Customizable component pattern for professional, product-grade UI. |

## Data & Forms

| Technology | Purpose |
|---|---|
| TanStack Table | Table engine for sorting, filtering, and pagination. |
| React Hook Form | Efficient form state management with strong rendering performance. |
| Zod | Schema validation for forms and API payloads. |

## Visualization & UX

| Technology | Purpose |
|---|---|
| Recharts | Dashboard charts such as bar, line, area, and pie charts. |
| Motion | Framer Motion successor package for smooth UI animation. |
