# Frontend

Next.js 16 frontend for the Hospital Knowledge Assistant.

## Stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui component conventions
- TanStack Table, React Hook Form, Zod
- Recharts and Motion

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run typecheck
```
