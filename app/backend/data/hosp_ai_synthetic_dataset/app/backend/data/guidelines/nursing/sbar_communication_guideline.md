# SBAR Communication Guideline

## Purpose
Provide a standardized Situation, Background, Assessment, Recommendation handoff for nurses and clinicians using the HMS AI assistant. This document is synthetic and for software testing only.

## Situation
State patient name, MRN, location, current concern, and urgency. Example: Patient has new dyspnea, SpO2 90% RA, HR 118, BP 96/58.

## Background
Summarize active diagnoses, allergies, recent medications, relevant labs, and code status if available. Include anticoagulants, insulin, sedatives, renal labs, and recent procedures.

## Assessment
Report focused assessment: airway, breathing, circulation, neuro status, pain score, wound status, intake/output, and patient response to interventions.

## Recommendation
Ask for a specific action: evaluate patient now, order labs, review medication, approve transfer, or clarify plan. Read back urgent orders.

## Documentation
Record time, recipient, recommendation, response, and follow-up. Access to AI summaries must respect patient permission scope and audit requirements.
