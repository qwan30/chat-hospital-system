RAG Pipeline

5-stage retrieval pipeline per query:

  1. Permission check (ABAC + RBAC)
  2. Query embedding (Ollama or deterministic)
  3. Hybrid retrieval (vector + BM25 + Graph RAG)
  4. Reranking (cross-encoder or score-based)
  5. Grounded generation (Simple QA / Decompose QA / Patient Summary)

Every answer is citation-validated before returning to the user.

LLM Manager Pattern

Multi-provider abstraction, runtime-switchable:

  • StubLLM: Deterministic testing provider
  • OllamaLLM: Local Qwen2.5 3B/7B via REST
  • OpenAILLM: OpenAI, Azure, Groq, Together, Mistral

All providers implement BaseLLM (generate + stream). Configured via chat_provider setting.

Soft Delete Pattern

9 tables use deleted_at for soft deletion: users, patients, patient_permissions, documents, document_pages, document_chunks, chat_threads, chat_thread_participants.

Immutable tables (audit_logs, ai_queries, chat_messages, retrieved_evidence) are append-only.
