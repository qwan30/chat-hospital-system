## Executive Summary

Implement an automated AI Quality Gate and Regression Drift Detector for GitHub Actions CI. This system reads candidate evaluation results generated by `scripts/run_ai_evaluation.py`, compares them against a version-locked baseline snapshot (`baseline-release.json`), and automatically enforces both **Hard Quality Gates** (Zero PHI Leakage, Recall $\ge 0.90$, Faithfulness $\ge 90\%$, Zero OCR Decimal Misreads) and **Relative Drift Tolerances** (Faithfulness drop $\le 2\%$, Latency increase $\le 20\%$).

---

## User Review Required

> [!IMPORTANT]
> - **PR Quality Gate Behavior:** On Pull Requests, if any hard gate is violated or relative drift exceeds tolerance, the CI step will exit with status `1` and block PR merge.
> - **Output Artifacts:** Generates `drift_report.json` and renders an interactive Markdown table in `$GITHUB_STEP_SUMMARY`.

## Proposed Changes

### Component 1: Data Contracts (`app/backend/src/hospital_ai/evaluation/contracts.py`)

#### [MODIFY] [`contracts.py`](file:///d:/projects/chatbot-hospital-system/app/backend/src/hospital_ai/evaluation/contracts.py)
- Add Pydantic v2 schemas:
  - `MetricDriftComparison`: Individual metric delta, tolerance, directionality, and status.
  - `DriftViolation`: Specific hard gate or drift threshold failure detail.
  - `DriftGateResult`: Overall verdict (`GO` / `NO-GO`), violation list, and baseline/candidate commit hashes.

---

### Component 2: Drift Detector Engine (`app/backend/src/hospital_ai/evaluation/drift_detector.py`)

#### [NEW] [`drift_detector.py`](file:///d:/projects/chatbot-hospital-system/app/backend/src/hospital_ai/evaluation/drift_detector.py)
- Implement `evaluate_metric_drift(candidate_summary: dict, baseline_summary: dict) -> DriftGateResult`:
  - Directionality handling (e.g. `higher_is_better` for accuracy/recall vs `lower_is_better` for latency/error rates).
  - Hard gate checks: `unauthorized_evidence_count == 0`, `wrong_patient_citations_count == 0`, `recall_at_5 >= 0.90`, `faithfulness_rate >= 0.90`, `decimal_misread_count == 0`.
  - Relative drift checks: `faithfulness_rate` delta $\ge -0.02$, `answer_relevance_rate` delta $\ge -0.02$, `recall_at_5` delta $\ge 0.00$, `mean_latency_seconds` percentage increase $\le 20.0\%$.
  - Zero-division defensive math checks when baseline denominators are zero.

---

### Component 3: CLI Entrypoint (`app/backend/scripts/verify_ai_regression.py`)

#### [NEW] [`verify_ai_regression.py`](file:///d:/projects/chatbot-hospital-system/app/backend/scripts/verify_ai_regression.py)
- Argument parsing: `--candidate`, `--baseline`, `--output-report`, `--github-summary`, `--strict`.
- Reads input JSON files safely with error handling for missing/malformed inputs.
- Formats ANSI terminal output and GitHub Markdown Step Summary.
- Returns exit code `0` on `GO` and `1` on `NO-GO`.
